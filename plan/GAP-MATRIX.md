1. **AI vendor mismatch (blocks Day 5 start):** the plan wants `IAiProvider` with an Anthropic implementation; the existing code has OpenAI only, no abstraction. Three options, need your call before Day 5 work begins:
   - (a) Build the `IAiProvider` abstraction, keep OpenAI as the real implementation (rename the plan's vocabulary, not the code) — least work, matches what's already paid for/configured.
   - (b) Build the abstraction with both OpenAI and Anthropic implementations behind it — most flexible, most work.
   - (c) Replace OpenAI with Anthropic entirely, per the plan literally — requires a new API key/Vault secret, throws away the working `OpenAiAssistantService` integration.
2. **D3-T4's filter match is a false positive** — `FullyQualifiedName~Report` finds a real passing test, but it's unrelated to the acceptance criteria. Left as "Needs build" above so it isn't mistaken for done by a future session trusting the filter alone.
